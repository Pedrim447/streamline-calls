✏️ Editando direto no GitHub

Você pode editar arquivos diretamente pelo navegador:

Acesse o repositório

Abra o arquivo desejado

Clique no ícone de edição (lápis)

Faça as alterações e confirme o commit

☁️ Ambiente online de desenvolvimento

Outra opção é utilizar um ambiente online:

Acesse o repositório

Clique em Code

Acesse a aba de ambientes online

Crie um novo ambiente

Você poderá editar e rodar o projeto diretamente no navegador.
